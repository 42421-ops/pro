# SGX Detailing — PWA

Приложение для записи клиентов, работы сотрудников и управления студией детейлинга.
Устанавливается на телефон как обычное приложение и открывается без интернета.

## Что внутри

| Файл | Назначение |
|------|-----------|
| `index.html` | всё приложение (интерфейс и логика) |
| `manifest.json` | данные для установки на экран «Домой» |
| `sw.js` | офлайн-режим и кеш |
| `icons/` | иконки приложения |
| `_headers` | настройки кеша для Netlify / Cloudflare Pages |

## Как опубликовать (бесплатно, 5 минут)

Для установки на телефон нужен адрес с **HTTPS**. Файл, открытый с компьютера двойным кликом, как приложение не установится.

**Вариант 1 — Netlify Drop (проще всего)**
1. Откройте https://app.netlify.com/drop
2. Перетащите в окно всю папку `sgx-pwa`.
3. Получите адрес вида `https://название.netlify.app`. Его можно заменить на свой домен в настройках сайта.

**Вариант 2 — Cloudflare Pages:** создайте проект → Upload assets → загрузите папку.

**Вариант 3 — GitHub Pages:** загрузите файлы в репозиторий → Settings → Pages → Branch `main`.

## Как установить

- **iPhone (Safari):** открыть адрес → «Поделиться» → «На экран Домой».
- **Android (Chrome):** открыть адрес → меню ⋮ → «Установить приложение».
- **Компьютер (Chrome / Edge):** значок установки в адресной строке.

## Первый запуск: обязательно

1. Нажмите на замок в правом верхнем углу → «Администратор». Пароль по умолчанию **1234**. Смените: «Пароль».
2. «Сотрудники» → общий вход «Мастер», PIN по умолчанию **0000**. Смените.
3. Заполните услуги, часы работы, число боксов, контакты, при необходимости Telegram-бота.

## Как обновить приложение

1. Замените `index.html` новой версией.
2. В `sw.js` увеличьте номер: `const VERSION = 'sgx-v1'` → `'sgx-v2'`.
3. Загрузите файлы на хостинг заново. При следующем запуске у всех появится обновление.

## Важно знать

- Все данные (записи, услуги, настройки) хранятся **в браузере каждого устройства**. Запись, сделанную клиентом на его телефоне, администратор на своём устройстве не увидит.
  Пока это закрывает Telegram-бот: каждая заявка сразу приходит владельцу в чат.
  Чтобы записи были общими для всех устройств, нужна общая база данных (например, Firebase или Supabase).
- Пароли администратора и PIN сотрудников хранятся на устройстве. Это защита от случайного входа, а не от взлома.
- Очистка данных сайта в браузере удалит записи и настройки.
